# Sunset

Azərbaycan dilində, qaranlıq görünüşlü nümunə xəbər blogu. Bütün hekayələr **Nümunə** kimi işarələnib.

## Yerli açılış

`index.html` faylını brauzerdə aç və ya Python 3 ilə `npm run dev` əmrini işə sal.

## GitHub Pages

Repozitoriyada **Settings → Pages → Build and deployment** bölməsini aç:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)

**Save** düyməsini seç. GitHub Pages yayımlanmanı tamamladıqdan sonra canlı saytın keçidini həmin bölmədə göstərir.

## Funksiyalar

- Mobil, planşet və masaüstü görünüş
- Başlığa görə axtarış və kateqoriya filtrləri
- Məqalə oxuma pəncərəsi
- Nümunə abunə forması (məlumat saxlamır)

Dil və görünüş seçimləri vizualdır. Layihə real xəbərlər yayımlamır.
